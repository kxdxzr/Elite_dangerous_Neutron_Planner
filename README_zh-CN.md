# Elite Dangerous 中子星规划器

[English](README.md) · [简体中文](README_zh-CN.md)

为《Elite Dangerous》玩家提供的 Windows 桌面小工具：保存常用配船和目的地，按顺序设置途经点，再通过 Spansh 规划适合当前配船的中子星航线。

**它只是对 [Spansh 已有的舰船航线规划工具](https://spansh.co.uk/exact-plotter)做了一点桌面端扩展，本质上仍然是使用 Spansh 的规划服务，并非另写了一套规划算法。** 实际航线计算由 Spansh 完成，核心规划能力归功于 Spansh。如果不需要本地收藏和桌面操作，直接使用 Spansh 网页即可。

本工具非 Frontier／Spansh 官方产品。当前版本为 **0.1.0**，可能存在 Bug，请在游戏中核对路线和燃油情况。

## 能做什么

- **保存常用配船**：导入 Coriolis JSON 或 EDSY SLEF，为不同配船命名收藏。
- **收藏目的地**：保存常去的星系，之后一键填入终点；支持重命名和删除。
- **按途经点规划**：依次经过指定星系，可调整途经点顺序。
- **从游戏日志填写起点**：点击“使用当前星系”，读取本机 Journal 最近记录的位置，无需手动抄写星系名。
- **调整规划条件**：默认启用中子增压，可设置货物、储备燃油、注入和算法等选项。
- **查看和带走结果**：预览普通／中子增压满油跳距，复制结果星系名或导出 CSV。
- **回看最近规划**：本地保留最近 5 次规划的参数和结果，重启后仍可查看；Spansh 标记含中子星的星系行以蓝色突出显示。
- **按习惯使用**：中英文切换、跟随系统／浅色／深色主题，重启后恢复设置和收藏。
- **整页上下滚动**：设置、规划按钮和结果在同一页，不再上下分区。滚轮滚动整页；长路线可拖动表格右侧滚动条，更多列可用底部横向滚动条查看。

## 下载与启动

从 [Release 页面](https://github.com/kxdxzr/Elite_dangerous_Neutron_Planner/releases/tag/v0.1.0)下载 **0.1.0**：

1. 在 **Assets** 下载 `EliteDangerousNeutronPlanner-Windows-v0.1.0.zip`。
2. 解压后运行 `EliteDangerousNeutronPlanner.exe`，无需安装 Python。
3. 可选：使用 `SHA256SUMS.txt` 校验下载文件；页面也提供源码和许可说明。

配船属性首次解析需要联网获取模组数据；航线规划需要连接 Spansh。

## 第一次规划

1. 点击“新增舰船配置”，输入收藏名称，粘贴配船 JSON，或点击“导入 JSON 文件”。**这里需要配船数据文件，不是 Coriolis／EDSY 网页链接。**
2. 保存并选中配船，检查显示的船型和满油跳距。
3. 填写起点与终点星系；如需中途停留，添加途经点并调整顺序。
4. 按实际情况设置货物、储备燃油等选项，然后点击“规划航线”。
5. 查看结果，按需复制星系名或导出 CSV。

### 收藏常去的目的地

在“终点星系”填写星系，点击“收藏当前终点”并命名。下次从“目的地收藏”中选择，点击“设为终点”即可复用。

收藏重启后仍保留，同名收藏不会被覆盖。保存收藏不会联网验证星系，也不会自动开始规划；星系会在规划时解析。

### 用游戏中的位置作为起点

进入游戏后点击“使用当前星系”，软件会读取最新活动 Journal 会话中的位置，并显示记录时间。
默认日志目录为 `%USERPROFILE%\Saved Games\Frontier Developments\Elite Dangerous`；找不到时，可点击“选择游戏日志文件夹”指定目录，选择会在正常退出后记住。

这个按钮只读取一次、只更新起点，不会开始规划。**不会在启动时自动扫描或上传日志；持续跟随需要另外手动开启。**
位置来自 `Location`、`FSDJump` 或 `CarrierJump` 记录，不会把尚未到达的跳跃目标误当作当前位置。
退出游戏后的记录可能已经过时；多账号共用目录时使用最近活动的会话，请核对星系和时间。最新会话没有位置记录时会提示，不会退回其他会话的位置。

### 跟随路线位置与自动复制下一跳

规划或载入结果后，在结果区开启“跟随游戏位置”，软件约每 2 秒检查一次本地 Journal，正常情况下仅读取新增内容。
当前位置在路线中时，对应行显示为绿色，并显示原路线中的位置、日志时间和计划下一跳。**不会自动滚动或改变排序**，需要时可点击“定位当前行”。

再开启“自动复制计划下一跳”，就会把下一星系的纯名称写入系统剪贴板，你可以直接切回游戏粘贴；不模拟按键，也不切换焦点。
**这会替换剪贴板原有内容。每条当前路线的同一位置只自动复制一次**，不会每次检查日志都覆盖剪贴板。

- 不在路线中时，只清除旧的位置标记和跟随提示；不复制、不弹偏航提示、不重新规划，也不修改起点。
- 到达终点时不再复制。未完成路线只跟随已验证的部分，到其末尾会明确标注“路线未完成”。
- 下一跳始终按原始路线顺序判断，与当前表格排序无关。
- 同一星系在路线中出现多次且无法确定位置时，不猜测或复制；选中对应行后点击“确认所选位置”。
- 两个开关每次启动均默认关闭。关闭跟随或退出软件即停止读取；读取、匹配和自动复制均不额外联网。

此功能只使用日志最近确认的位置，不代表游戏内实时导航；仍请核对记录时间、下一跳和补油条件。目前没有悬浮窗口。

### 查看最近结果，避免重复搜索

在“最近5次规划”中选择记录，点击“查看历史结果”，可恢复当时的参数与结果，并继续复制或导出，不会重新提交航线任务。
如果原配船已删除或修改，历史结果仍可查看，但再次规划前需要重新选择配船。

当前结果完整且配船、起终点、途经点和规划选项均未变化时，再点“规划航线”不会重复查询。失败或停止的规划仍可用相同参数重试。
历史中的未完成结果仍会保留未完成标记，导出时也需要确认。

如果切换参数后再次搜索，最近 5 次记录中 **24 小时内、配船及所有参数完全一致的完整结果**也会直接复用，并明确显示“历史结果，未重新查询”和原记录时间。不会用未完成结果代替新的规划。

为减少准备时间，常用星系的解析结果会在本次运行中缓存，多个航点会以有限并发解析；分段航线仍按顺序计算。
进度区会区分配船处理、星系解析、Spansh 排队与计算，结束后显示分阶段耗时。**这些优化不能消除 Spansh 服务器本身的排队和计算时间。**

## 出发前请注意

- **每一段都假设主油箱满油出发。** 设置途经点后，不会继承上一段的到达油量，**也不保证途经点能够补油**。请自行确认补油条件。
- 跳距预览是理论满油数值，不代表当前位置可以中子增压，也不保证实际路线可行。
- “停止”会停止本地等待和后续分段提交，但不保证撤销 Spansh 已收到的任务。
- 规划中断或失败时，只保留已验证的完整分段；导出部分结果需要确认，不能当作完整路线使用。

更多细节见[规划说明](docs/route-planner.md)。

## 数据与隐私

设置、收藏和最近 5 次规划历史保存在本机 `%LOCALAPPDATA%\EliteDangerousNeutronPlanner`。历史文件 `route_history.json` 含航点、规划参数和路线结果，请勿在反馈问题时未经检查直接公开。收藏目的地和保存配船本身不会提交航线任务。

**开始规划会将所选配船和航点发送到 Spansh。** 请先移除不希望传输的私人字段。配船属性预览需要获取模组数据，但不会提交路线任务。
读取 Journal 本身只在本机进行；通过日志填入的起点，也只有在你开始规划时才会随航点发送到 Spansh。

### 从旧筛选器导入配船收藏

如果你用过 [Elite Dangerous 筛选器](https://github.com/kxdxzr/Elite_dangerous_Filter)中的规划器，可点击“导入旧版舰船收藏”，手动选择旧数据目录里的 `route_ship_favorites.json`。通常位于 `%LOCALAPPDATA%\EliteDangerousFilter`，旧源码版也可能在其项目 `data` 文件夹中。

导入不会修改或删除旧文件，名称冲突时会拒绝导入，不会覆盖。本工具与旧筛选器的数据分开保存。
